**Yes.** curl supports JSON transfer stats via `-w/--write-out` using the `%{json}` variable (and, since 7.83.0, `%{header_json}` for headers).

## Establishing commit

**`04c03416e68fd635a15cae8201872f5c29fdcca8`** — "writeout: support to generate JSON output" (Mathias Gumz, 2020-02-01).

This commit is an ancestor of the pinned HEAD (`ee521a1c889f4cde6905c5db117959917568be9b`); I verified it with `git merge-base --is-ancestor`, so it is genuinely in this checkout's history.

**Commit message (quoted):**

```
writeout: support to generate JSON output

This commit adds support to generate JSON via the writeout feature:

    -w "%{json}"

It leverages the existing infrastructure as much as possible. Thus,
generating the JSON on STDERR is possible by:

    -w "%{stderr}%{json}"

This implements a variant of
https://github.com/curl/curl/wiki/JSON#--write-out-json.

Closes #4870
```
