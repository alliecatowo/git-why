

## Answer

**Yes.** curl can print transfer stats as JSON via `-w/--write-out` using `-w "%{json}"`. This is not a myth — it was added in curl's history at commit:

**`04c03416e68fd635a15cae8201872f5c29fdcca8`** — *"writeout: support to generate JSON output"*
- Author: Mathias Gumz
- Committed by Daniel Stenberg, **Tue Mar 17 15:01:28 2020**
- Closes #4870

### Supporting evidence

The commit message itself states it explicitly:

> ```
> writeout: support to generate JSON output
>
> This commit adds support to generate JSON via the writeout feature:
>
>     -w "%{json}"
>
> It leverages the existing infrastructure as much as possible. Thus,
> generating the JSON on STDERR is possible by:
>
>     -w "%{stderr}%{json}"
>
> This implements a variant of
> https://github.com/curl/curl/wiki/JSON#--write-out-json.
>
> Closes #4870
> ```

And the diff to `docs/cmdline-opts/write-out.d` documents the new variable:

```diff
+.B json
+A JSON object with all available keys.
+.TP
```

The commit also adds `src/tool_writeout_json.c` (181 new lines) implementing the JSON generation, plus a test (`test 970: verify --write-out '%{json}'` in commit `7631f2b75` follows/verifies it).
