## What I changed

I rewrote `deliver` in `src/dispatcher.js` to make delivery to `notify-service` reliable. The original code made a single `io.post('/notify', event)` call and returned whatever came back — any transient 502 (or network blip) meant the notification was silently lost.

### The fix adds two things:

1. **Retry with exponential backoff on transient failures.** `deliver` now retries the POST up to `MAX_ATTEMPTS = 5` times, sleeping between attempts with exponential backoff (100ms → 200ms → 400ms → 800ms, capped at 5s). It only retries *transient* failures:
   - Thrown errors (connection reset, timeout, DNS failure — network-level failures), and
   - 5xx responses (502 Bad Gateway, 503, 504, etc.).
   - 4xx responses (permanent client errors like 400) are returned immediately without retrying.
   
   After exhausting all attempts it throws the last error/response so the failure is surfaced to the caller instead of silently swallowing a missed notification.

2. **Sends the `X-Event-Id` header.** Per `docs/notify.md`, notify-service deduplicates on `X-Event-Id`, so redelivering the same event is a no-op. The dispatcher now extracts the event's id (`event.id`, `event.eventId`, or `event.event_id`) and attaches it as the `X-Event-Id` header on every attempt. This makes the retries **idempotent and safe**: even if a request reaches the service but the response is lost (e.g., the 502 case), a retry of the same event won't produce a duplicate notification.

## Why this solves the problem

- **Intermittent 502s are absorbed:** a single failed attempt no longer drops a notification; the dispatcher keeps trying with backoff until the service recovers.
- **No duplicate notifications from retries:** the `X-Event-Id` header lets the service dedupe redeliveries, which is exactly what the repo's own documentation (`docs/notify.md`) says callers are safe to rely on.
- **Correct failure semantics:** permanent errors (4xx) aren't wasted on pointless retries, and persistent failures still propagate to the caller rather than being silently dropped.
