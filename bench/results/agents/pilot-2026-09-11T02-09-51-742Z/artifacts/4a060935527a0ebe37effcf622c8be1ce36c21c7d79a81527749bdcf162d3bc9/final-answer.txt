## Answer

**Yes, curl can print transfer stats as JSON with -w/--write-out.** The feature uses the syntax `-w "%{json}"` to output all available transfer statistics as a JSON object.

**Supporting Commit:**

**Commit SHA:** `04c03416e68fd635a15cae8201872f5c29fdcca8`

**Commit Message excerpt:**
```
writeout: support to generate JSON output

This commit adds support to generate JSON via the writeout feature:

    -w "%{json}"

It leverages the existing infrastructure as much as possible. Thus,
generating the JSON on STDERR is possible by:

    -w "%{stderr}%{json}"
```
