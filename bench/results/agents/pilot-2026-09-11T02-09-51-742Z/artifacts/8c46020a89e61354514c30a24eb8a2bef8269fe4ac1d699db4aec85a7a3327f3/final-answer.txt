## Summary

Yes, ripgrep's special ignore-file name has changed several times throughout its history. Here's the complete timeline:

### Answer to the Question

**The special ignore-file name used to be `.xrepignore` in the very early days of the project.**

### Historical Evolution

1. **Initial (`.xrepignore`)** - When the project was called `xrep`, the ignore file was named `.xrepignore`

2. **After renaming to ripgrep (`.rgignore`)** - When the project was renamed from `xrep` to `ripgrep` on September 8, 2016 (commit `a744ec1`), the ignore file name was changed to `.rgignore`. This commit shows the transition:
   - `$HOME/.xrepignore` → `$HOME/.rgignore`
   - `.xrepignore` → `.rgignore` in the IGNORE_NAMES constant

3. **Removal of `.agignore`** - On September 15, 2016 (commit `7cefc55`), `.agignore` support was removed from the list of checked ignore files

4. **Switch to `.ignore`** - On September 23-24, 2016 (commit `cc90511`), ripgrep switched from `.rgignore` to the more generic `.ignore` file name. This was done to align with The Silver Searcher project.
