## Answer

Yes, ripgrep's special ignore-file name used to be something other than `.ignore`. 

**The original name was `.xrepignore`**, which was used when the project was called "xrep" before being renamed to "ripgrep".

### Supporting Evidence

**Commit SHA: `065c449`** (File path filtering works and is pretty fast)
- **Date:** August 27, 2016
- **First introduction of `.xrepignore`**

In the `src/gitignore.rs` file added in this commit, the documentation states:
> "Besides, we need to implement this logic anyway to support things like an .xrepignore file."

**Commit SHA: `7a149c2`** (More progress. With coloring!)
- **Date:** September 5, 2016
- **IGNORE_NAMES constant introduced**

This commit established the `IGNORE_NAMES` list with three entries:
```rust
const IGNORE_NAMES: &'static [&'static str] = &[
    ".gitignore",
    ".agignore",
    ".xrepignore",
];
```

**Timeline of changes:**
1. `.xrepignore` → added in commit 065c449 (Aug 27, 2016)
2. `.xrepignore` renamed to `.rgignore` → in commit a744ec1 (after project renamed to ripgrep)
3. `.agignore` removed → in commit 7cefc55 (Sep 15, 2016)
4. `.rgignore` switched to `.ignore` → in commit cc90511 (Sep 23, 2016), which states: "Switch from .rgignore to .ignore. But don't actually remove support for .rgignore until the next semver bump."
