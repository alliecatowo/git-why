## Summary

The requests library **did** switch from `chardet` as its text-encoding guesser to `charset_normalizer`. The commit that establishes this is:

**`2ed84f55b22f19a1e1e8eea2e50963dce62052d3`** — "Switch LGPL'd chardet for MIT licensed charset_normalizer (#5797)" by Ash Berlin-Taylor, July 7, 2021. This commit is an ancestor of the current HEAD.

### Why the switch happened

The commit message explains the motivation directly:

> "Although using the (non-vendored) chardet library is fine for requests itself, but using a LGPL dependency the story is a lot less clear for downstream projects, particularly ones that might like to bundle requests (and thus chardet) in to a single binary... By including an LGPL'd module it is no longer clear if the resulting artefact must also be LGPL'd.
>
> By changing out this dependency for one under MIT we remove all license ambiguity."

So the reason was **licensing**: `chardet` is LGPL-licensed, which creates uncertainty for projects that want to bundle requests in a single binary. Replacing it with the MIT-licensed `charset_normalizer` removes that ambiguity.
