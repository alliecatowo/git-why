**Yes.** ripgrep's special ignore-file name used to be **`.rgignore`**. It was only changed to `.ignore` later.

### Supporting commit

**`cc90511ab29d3c37e873acac0fd80f90473f54bb`** — *"Switch from .rgignore to .ignore."* (Andrew Gallant, Fri Sep 23 22:44:17 2016 -0400). This commit is reachable from the pinned `HEAD`.

The commit message says it explicitly:

```
Switch from .rgignore to .ignore.

But don't actually remove support for .rgignore until the next semver
bump.

Note that this puts us in line with the silver searcher:
https://github.com/ggreer/the_silver_searcher/pull/974

Fixes #40
```

The diff shows `.ignore` being **added** to the ignore-name list while `.rgignore` was retained:

```diff
 const IGNORE_NAMES: &'static [&'static str] = &[
     ".gitignore",
+    ".ignore",
     ".rgignore",
 ];
```

Before this commit (`cc90511^`), the list was just `[".gitignore", ".rgignore"]`, so `.rgignore` was the ripgrep-specific name.

### Even earlier

The project was briefly called **`xrep`**, and its special ignore name was **`.xrepignore`**. Commit **`a744ec133d12e0c8d8e8b0486cd92e2b60ad61e6`** (*"Rename xrep to ripgrep."*) renamed it:

```diff
 1. Specify an ignore rule in some "global" configuration, such as a
-   $HOME/.xrepignore or on the command line.
+   $HOME/.rgignore or on the command line.
 ...
 const IGNORE_NAMES: &'static [&'static str] = &[
     ".gitignore",
     ".agignore",
-    ".xrepignore",
+    ".rgignore",
 ];
```

So the lineage of the special name is: `.xrepignore` (xrep era) → `.rgignore` (rename to ripgrep) → `.ignore` (commit `cc90511`, with `.rgignore` kept for backward compatibility). The later commit `7cefc55` also shows `.agignore` (borrowed from The Silver Searcher) was dropped from the list in Sept 2016.

No files were modified (`git status` shows only the pre-existing untracked `.zvec-grep/` index directory).
