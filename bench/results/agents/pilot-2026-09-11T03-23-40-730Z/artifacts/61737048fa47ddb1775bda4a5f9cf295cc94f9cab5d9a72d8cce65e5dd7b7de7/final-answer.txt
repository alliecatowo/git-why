## Answer

**Yes.** In ripgrep's early days, the special (non-`.gitignore`) ignore file was named **`.rgignore`**, not `.ignore`. It was switched to `.ignore` in commit **`cc90511ab29d3c37e873acac0fd80f90473f54bb`** ("Switch from .rgignore to .ignore.", 2016-09-23), with `.rgignore` retained for backward compatibility.

### The establishing commit

```
commit cc90511ab29d3c37e873acac0fd80f90473f54bb
Author: Andrew Gallant <jamslam@gmail.com>
Date:   Fri Sep 23 22:44:17 2016 -0400

    Switch from .rgignore to .ignore.

    But don't actually remove support for .rgignore until the next semver
    bump.

    Note that this puts us in line with the silver searcher:
    https://github.com/ggreer/the_silver_searcher/pull/974

    Fixes #40
```

### Supporting diff excerpt

The actual behavioral change is in `src/ignore.rs`, adding `.ignore` to the recognized ignore-file names while keeping `.rgignore`:

```diff
 const IGNORE_NAMES: &'static [&'static str] = &[
     ".gitignore",
+    ".ignore",
     ".rgignore",
 ];
```

The docs were updated to match, e.g. in `README.md`:

```diff
-The above command also respects all `.rgignore` files, including in parent
-directories. `.rgignore` files can be used when `.gitignore` files are
-insufficient. In all cases, `.rgignore` patterns take precedence over
+The above command also respects all `.ignore` files, including in parent
+directories. `.ignore` files can be used when `.gitignore` files are
+insufficient. In all cases, `.ignore` patterns take precedence over
 `.gitignore`.
```

And a test was added for the new name (`tests/tests.rs`):

```rust
sherlock!(ignore_generic, "Sherlock", ".", |wd: WorkDir, mut cmd: Command| {
    wd.create(".ignore", "sherlock\n");
    wd.assert_err(&mut cmd);
});
```

### Corroborating detail

Immediately before this commit (`git show cc90511^:src/ignore.rs`), the list was:

```rust
const IGNORE_NAMES: &'static [&'static str] = &[
    ".gitignore",
    ".rgignore",
];
```

An even earlier commit, `7cefc55238bc23f8b329410520242046dea9ef33` ("Remove .agignore from ignore file list."), shows `.agignore` (the Silver Searcher's file) had also briefly been supported before being dropped.

### Conclusion

The special ignore-file name was originally **`.rgignore`**. Commit `cc90511ab29d3c37e873acac0fd80f90473f54bb` renamed the *primary* special ignore file to `.ignore` (aligning with The Silver Searcher), while intentionally continuing to honor `.rgignore` until a later semver bump. This commit is an ancestor of the pinned HEAD (`3fce3b5bb0236da2df6d99672afb8a719642eca7`). No files were modified.
