**Yes — the option was renamed from `FIRST` to `RANK`.**

LPOS was first added under the temporary name `LRANK` (commit `a7936ef96`, "LRANK: Add command (the command will be renamed LPOS)"), then implemented as `LPOS` with an option token of `FIRST`. ### Why your memory is correct

The `FIRST` spelling only ever existed during the brief development window in June 2020:
- `ca58198` (2020‑06‑12, "help.h updated.") still documented `key element [FIRST rank] ...`.
- `a5a3a7b` (2020‑06‑24) renamed it to `RANK` before the command was publicly released (LPOS shipped in Redis 6.0.6 / 6.2.0). So early internal examples/tests used `FIRST`, but no released version did.
