## Answer

**Yes** — ripgrep's special ignore-file name used to be **`.rgignore`** before it was changed to **`.ignore`**.

### Supporting commit

**SHA: `cc90511ab29d3c37e873acac0fd80f90473f54bb`**

Fixes #40

### Context
- `.rgignore` was ripgrep's original custom ignore-file name, present from the very early "draft"/initial-implementation commits (e.g. `f9bf1e4` "draft", `49003e8` "Add man page.", `a744ec1` "Rename xrep to ripgrep.").
- On **2016-09-23**, commit `cc90511` added `.ignore` as the new name while keeping `.rgignore` working for backward compatibility ("don't actually remove support for .rgignore until the next semver bump"), explicitly aligning with The Silver Searcher's convention (referencing `ggreer/the_silver_searcher#974`) and closing issue #40.
- `.rgignore` support was fully documented as a legacy/secondary name for a long time afterward (it still appears alongside `.ignore` in the current `crates/core/flags/defs.rs`, e.g. `"Don't use .ignore or .rgignore files."`), confirming `.rgignore` was the original special ignore-file name before `.ignore` became primary.
