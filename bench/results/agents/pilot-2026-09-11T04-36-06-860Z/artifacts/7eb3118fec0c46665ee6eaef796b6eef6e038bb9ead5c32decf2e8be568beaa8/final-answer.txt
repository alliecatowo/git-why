## Answer

**Yes**, curl can print transfer stats as JSON with `-w`/`--write-out` using the `%{json}` variable (e.g., `-w "%{json}"`, or `-w "%{stderr}%{json}"` to send it to stderr).

### Supporting commit

**`04c03416e68fd635a15cae8201872f5c29fdcca8`** — "writeout: support to generate JSON output" (Mathias Gumz, 2020-02-01/committed 2020-03-17). This commit is an ancestor of the repository's current `HEAD` (`ee521a1c889f4cde6905c5db117959917568be9b`), so the feature is present at the pinned commit.
