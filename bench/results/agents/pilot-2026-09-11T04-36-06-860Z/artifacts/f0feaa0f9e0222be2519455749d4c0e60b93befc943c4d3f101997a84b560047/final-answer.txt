## Answer

**Yes** — curl can print transfer stats as JSON with `-w`/`--write-out` using the `%{json}` variable, exactly as you remembered.

**Author/Date:** Mathias Gumz, Sat Feb 1 2020 — `writeout: support to generate JSON output`

**Commit message excerpt** (quotes the exact syntax you were thinking of):

> This commit adds support to generate JSON via the writeout feature:
>
>     -w "%{json}"
>
> It leverages the existing infrastructure as much as possible. Thus, generating the JSON on STDERR is possible by:
>
>     -w "%{stderr}%{json}"
>
> This implements a variant of https://github.com/curl/curl/wiki/JSON#--write-out-json.
>
> Closes #4870
