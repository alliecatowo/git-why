Yes, the default handling of unknown keys changed in Zod. 

### Timeline of Unknown Key Handling in Zod:
1. **Before Zod 2 (Zod v1):** Zod object schemas disallowed unknown keys by default and threw an error if they were present.
2. **During Zod v2 Development:** The default behavior was initially changed to allow (pass through) unknown keys.
3. **Zod v2 Release:** Ultimately, the default behavior was changed to **strip** unknown keys by default.

---
