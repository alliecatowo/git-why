**Yes, the default handling of unknown keys in Zod objects did change.** 

Originally in Zod version 1, unknown keys were not allowed by default (causing an error to be thrown). During the development of Zod version 2, Zod briefly changed to allow/passthrough unknown keys by default. However, this was changed so that **unknown keys are stripped by default**.
