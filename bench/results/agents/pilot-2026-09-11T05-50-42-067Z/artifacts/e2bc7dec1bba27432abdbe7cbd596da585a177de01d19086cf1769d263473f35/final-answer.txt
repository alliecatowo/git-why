Yes, the default handling of unknown keys in Zod object schemas changed. 

Historically, the progression of default unknown key handling has been:
1. **Zod v1**: Zod objects were **strict** by default—meaning they rejected unknown keys and threw an error if extra properties were passed.
2. **Early Zod v2 pre-releases**: The default was changed to **allow/passthrough** unknown keys (extra keys were kept in the parsed output).
3. **Zod v2.0.0-beta.1 onwards**: The default was changed to **strip** unknown keys. This is when extra keys started disappearing by default.
