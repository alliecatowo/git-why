### Bonus: an even earlier name

Two prior commits show the name history goes back further, to when the tool itself was called `xrep`:

- `065c44998092906746f6585090bafbf36d98342b` — "File path filtering works and is pretty fast." (2016-08-27) introduced the original custom ignore file as **`.xrepignore`**, e.g. `builder.add_path(id.path.join(".xrepignore"))` and `$HOME/.xrepignore`.
- `a744ec133d12e0c8d8e8b0486cd92e2b60ad61e6` — "Rename xrep to ripgrep." (2016-09-08) renamed it to `.rgignore`:
  ```diff
   const IGNORE_NAMES: &'static [&'static str] = &[
       ".gitignore",
       ".agignore",
  -    ".xrepignore",
  +    ".rgignore",
   ];
  ```

So the progression was `.xrepignore` → `.rgignore` → `.ignore`. Note `.rgignore` was never fully dropped — at the pinned commit it still exists as a ripgrep-specific custom ignore filename (`crates/core/flags/hiargs.rs:916`: `builder.add_custom_ignore_filename(".rgignore");`), applied in addition to `.ignore`.

No files were modified.
