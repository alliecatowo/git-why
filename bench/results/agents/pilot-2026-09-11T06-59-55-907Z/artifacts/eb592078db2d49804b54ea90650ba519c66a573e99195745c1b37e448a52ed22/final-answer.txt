Your memory is correct. ripgrep's tool-specific ignore file was originally named **`.rgignore`**, not `.ignore`. It was renamed to `.ignore` about a month after the project's first release.

### The commit that establishes it

**`cc90511ab29d3c37e873acac0fd80f90473f54bb`** — "Switch from .rgignore to .ignore." (Andrew Gallant, Fri Sep 23 2016), released in ripgrep 0.2.0.

Commit message, quoted in full:

> ```
> Switch from .rgignore to .ignore.
>
> But don't actually remove support for .rgignore until the next semver
> bump.
>
> Note that this puts us in line with the silver searcher:
> https://github.com/ggreer/the_silver_searcher/pull/974
>
> Fixes #40
> ```

The diff adds the new name to the ignore-file list in `src/ignore.rs`, keeping the old one for backwards compatibility:

```diff
 const IGNORE_NAMES: &'static [&'static str] = &[
     ".gitignore",
+    ".ignore",
     ".rgignore",
 ];
```

and updates the docs, e.g. in `README.md`:

```diff
-The above command also respects all `.rgignore` files, including in parent
-directories. `.rgignore` files can be used when `.gitignore` files are
-insufficient. In all cases, `.rgignore` patterns take precedence over
+The above command also respects all `.ignore` files, including in parent
+directories. `.ignore` files can be used when `.gitignore` files are
+insufficient. In all cases, `.ignore` patterns take precedence over
 `.gitignore`.
```

It also adds a regression test in `tests/tests.rs` for the new name, alongside the existing `ignore_ripgrep` test:

```diff
+sherlock!(ignore_generic, "Sherlock", ".", |wd: WorkDir, mut cmd: Command| {
+    wd.create(".ignore", "sherlock\n");
+    wd.assert_err(&mut cmd);
+});
```

### Bonus: one earlier name too

Before the project was even called ripgrep, the file was `.xrepignore` (the tool was originally named `xrep`). Commit **`a744ec133d12e0c8d8e8b0486cd92e2b60ad61e6`** ("Rename xrep to ripgrep.", Thu Sep 8 2016) did that rename in `src/ignore.rs`:

```diff
     ".gitignore",
     ".agignore",
-    ".xrepignore",
+    ".rgignore",
```

So the full lineage is: `.xrepignore` → `.rgignore` → `.ignore`.

### Note on the "next semver bump"

Despite the commit message's intent, `.rgignore` support was never actually removed — it is still honored at the pinned commit, now via the `ignore` crate's custom-filename mechanism (`crates/core/flags/hiargs.rs:916`: `builder.add_custom_ignore_filename(".rgignore");`), and it's still documented in the `--no-ignore-dot` help text. Later commits refined this, e.g. `f3241fd` ("cli: '--no-ignore-dot' should also '.rgignore'", fixing #2198).
