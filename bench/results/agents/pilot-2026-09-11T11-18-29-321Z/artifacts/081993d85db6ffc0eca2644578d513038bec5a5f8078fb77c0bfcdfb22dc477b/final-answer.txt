3. **What was that bug where things went wrong when a file ended up with handle number zero?**

   - **Commit:** `c9aa586`
   - **Quote:** "`open()` can return any non-negative integer on success, including zero. This change modifies the check from open()'s return value to also include checking for a return value of zero."
