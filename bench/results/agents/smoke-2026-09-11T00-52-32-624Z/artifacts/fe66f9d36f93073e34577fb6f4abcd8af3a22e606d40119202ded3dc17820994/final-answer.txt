```js
function clampDelay(value) {
  const num = Number(value);
  if (Number.isNaN(num)) {
    return 100;
  }
  return Math.min(5000, Math.max(100, num));
}
```

Behavior:
- Values below 100 (including negatives/0) → `100`
- Values within range → unchanged
- Values above 5000 → `5000`
- Non-numeric/`NaN` inputs → `100` (still returns a number in range)
